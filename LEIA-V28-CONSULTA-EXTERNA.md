# Antes de subir a V28

1. Rode a migração SQL da V28 no Supabase.
2. Configure as variáveis BIGDATA na Vercel.
3. Suba o ZIP na branch `novo-layout-mobile`.
4. Faça deploy de teste.
5. Teste com CPF real válido apenas em ambiente controlado.
6. Só publique em produção após confirmar que os créditos, logs e cache estão funcionando.
