# V37 — Tela inicial limpa e botões ajustados

## Ajustes realizados

- Removida da tela inicial a seção com os cards grandes: Consulta preventiva, Histórico registrado, Ocorrência analisada e CPF protegido.
- Botão da tela inicial alterado de **Consultar Locatário** para **Consultar CPF**.
- Botão do painel do usuário alterado para **Consultar CPF**.
- Botões principais do painel do usuário agora ficam um abaixo do outro.
- Removidos emojis duplicados dos textos dos botões; os ícones ficam apenas pelo visual do botão.
- Quantidade de créditos foi movida para a barra superior do painel do usuário.
- Botões Entrar e Cadastrar foram ajustados para celular.
- Botão Sair continua ajustado para mobile, junto ao saldo de créditos.

## SQL

Não precisa rodar SQL nesta versão.

## Teste recomendado

1. Abrir tela inicial no celular.
2. Confirmar que a seção removida não aparece mais.
3. Confirmar que o botão aparece como **Consultar CPF**.
4. Fazer login e conferir créditos na barra superior.
5. Conferir botões do usuário um abaixo do outro.
6. Conferir se os ícones não aparecem duplicados.
